    Emel pelanggan

    Emel dijana oleh dashboard dan menunggu untuk dihantar melalui Resend.

    Belum disambung ke Resend. Emel di bawah disimpan dalam baris gilir. Ia akan dihantar setelah server kecil disediakan (langkah di bawah). API key Resend mesti disimpan di server, bukan dalam laman ini.

    Sambung Resend (langkah untuk developer)

    1. Daftar di resend.com dan tambah domain cucikarpet.co. Masukkan rekod DNS (SPF & DKIM) yang Resend beri di tempat anda beli domain, kemudian tunggu status "Verified".
    2. Cipta API key di Resend dengan kebenaran "Sending access" sahaja. Simpan sebagai rahsia server bernama RESEND_API_KEY (contoh: Supabase Edge Function secrets atau Vercel Environment Variables). Jangan letak dalam kod laman web.
    3. Bila sistem dipindahkan ke Supabase, jadual outbox mengikut medan yang sama seperti di sini: to, subject, text, orderNo, status.
    4. Server function menghantar setiap emel berstatus queued, kemudian tukar kepada sent dengan id daripada Resend.
    // Contoh server function (Node / Supabase Edge / Vercel)
const res = await fetch("https://api.resend.com/emails", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${process.env.RESEND_API_KEY}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    from: "cucikarpet.co <order@cucikarpet.co>",
    to: [mail.to],
    reply_to: "order@cucikarpet.co",
    subject: mail.subject,
    text: mail.text,
  }),
});
const { id } = await res.json();   // simpan id ini, tanda status = "sent"
